# Project TOYBOX — AI 인터랙티브 캐릭터 기술 기획서

유니버설 스튜디오 동키 미트앤그리트(숨은 성우가 실시간으로 연기하는 인터랙티브 퍼펫)를
레퍼런스로, 목소리·움직임·대화·인터랙션·유머를 전부 AI로 구현하는 시스템의 전체 수행 계획.

- 문서: [`plan.html`](./plan.html) — 브라우저로 직접 열면 됩니다.
- 버전: v0.1 (2026-08-31)
- 첫 MVP: 토이스토리 버즈 라이트이어, 1인 대면 키오스크, 17주

## 담고 있는 것

| 장 | 내용 |
|---|---|
| 00 | IP·음성권 전제 조건과 병행 트랙(A: 토이스토리 / B: 오리지널) |
| 01 | 동키 성우의 작업 분해 → 개발 백로그 |
| 02 | KPI 10종과 측정 방법 |
| 03 | 7스테이지 파이프라인 아키텍처, 이벤트 스키마, 프롬프트 구조 |
| 04 | 900ms 지연 예산과 체감 지연 단축 전략 |
| 05 | 유머 엔진 (웃음 소스 4종, beat 타이밍, roast 강도 다이얼) |
| 06 | 4중 가드레일, 개인정보 처리 원칙, 예외 시나리오 |
| 07 | MVP 스코프와 수용 기준 7개 |
| 08 | 17주 로드맵 (P0~P4, 페이즈별 게이트) |
| 09 | 팀 5.5 FTE, 하드웨어 BOM, 총예산 |
| 10 | 세션당 운영 원가 계산식 |
| 11 | 리스크 레지스터 |
| 12 | 저장소 구조와 착수 2주 체크리스트 |
