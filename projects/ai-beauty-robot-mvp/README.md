고객 반응을 학습**하는 피지컬 AI 카운슬러의 MVP 계획과 실행 가능한 스캐폴드.

## 3줄 요약

- **범위**: "얼굴을 찍으면 90초 안에 로봇이 나에게 맞는 화장품 2개를 집어서 내밀어 준다" — 로봇이 사람 얼굴에 바르는 것은 MVP에서 제외
- **예산·기간**: 자체 개발 기준 약 **2,900만원 / 16주** (학습 2주 + 개발 14주, 게이트 4개)
- **난이도를 낮추는 3가지 트릭**: ① 제품을 **고정 슬롯 지그**에 세워 '비전 픽킹'을 제거 ② **인클로저 + 배출 슈트**로 사람·로봇 물리 분리 ③ 피부분석 AI는 **직접 만들지 않고 API 구매**

> 금액은 2025~2026년 기준 추정치이며 실제 견적에 따라 달라집니다.
> 법규 항목은 실무 체크리스트이지 법률 자문이 아닙니다 — 매장 파일럿 전 전문가 검토가 필요합니다.
