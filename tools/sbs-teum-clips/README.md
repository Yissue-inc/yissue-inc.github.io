# SBS '틈만나면,' 클립 목록 수집기

[클립 목록 페이지](https://programs.sbs.co.kr/enter/teum/clips/82063)의 "더보기"를 끝까지 눌러
전 회차 클립 제목을 모으고, 제목에서 **게임 이름을 추출해 정리**합니다.

> **본인 PC에서 실행하세요.** Claude Code 웹 세션은 아웃바운드 정책상 SBS·나무위키를 포함한
> 일반 웹에 접근할 수 없습니다.

## 설치 및 실행

```bash
cd tools/sbs-teum-clips
npm install
npx playwright install chromium

node scrape-clips.js --channel chrome
```

## 옵션

| 옵션 | 설명 |
|---|---|
| `--url <url>` | 클립 목록 페이지 (기본: SBS 틈만나면 클립 목록) |
| `--filter <str>` | 이 문자열을 포함한 링크만 수집 (기본: `/enter/teum/`) |
| `--out <dir>` | 저장 위치 (기본: `./output`) |
| `--max-pages <n>` | "더보기" 클릭 최대 횟수 (기본: 300) |
| `--channel <name>` | 설치된 실제 브라우저 사용 (`chrome`, `msedge`) |
| `--executable <p>` | 브라우저 실행 파일 직접 지정 |
| `--headless` | 창 없이 실행 (기본은 창 표시) |
| `--from <file>` | 크롤링을 건너뛰고 기존 `clips.json` 으로 게임 목록만 다시 뽑음 |

`--from`이 있어 추출 규칙을 고쳐가며 재실행할 때 사이트를 다시 긁지 않아도 됩니다.

## 결과물

```
output/
├── clips.json   전체 클립 (제목·URL·날짜·단계)
├── clips.csv    같은 내용의 표 — 엑셀/시트로 바로 열림
└── games.md     추출된 게임 이름 + 근거 클립 링크
```

## 동작 방식

**링크 수집은 CSS 클래스에 의존하지 않습니다.** 프로그램 경로(`/enter/teum/`)를 가리키면서
`/clip/` 또는 `/vod/`를 포함하는 `a` 태그를 전부 훑습니다. 제목은 `title` 속성 →
내부 `img[alt]` → 링크 텍스트 순으로 폴백하므로 SBS가 마크업을 바꿔도 잘 버팁니다.

**게임 이름 추출은 두 경로입니다.**

1. **따옴표 인용** — `'병 위의 탁구공 맞히기'` 처럼 제목에 이름이 그대로 박힌 경우
2. **문맥 추정** — `딱지 2개 넘기기 한 번에 성공` 처럼 따옴표가 없는 경우.
   `성공`/`실패` 앞 최대 6어절에서 모든 1~4어절 n-gram을 만든 뒤 점수로 거릅니다

후보가 게임 이름으로 인정되려면 **사물이 들어가거나 동작으로 끝나야** 합니다
(`탁구공`, `딱지`, `공기` … / `맞히기`, `넘기기`, `판치기` …).
이 관문이 `미션`, `틈 미션`, 유재석 별명 `게임 구멍` 같은 진행 용어·별명을 걸러냅니다.
앞뒤에 붙은 진행 용어는 잘라내고(`멤버들 딱지 2개 넘기기` → `딱지 2개 넘기기`),
더 긴 이름에 통째로 포함되는 부분 문자열은 흡수합니다(`공기` → `협동 공기`).

관문을 넘지 못한 따옴표 문구는 버리지 않고 `games.md` 하단에 원문 그대로 남깁니다.
별명·대사가 대부분이지만 놓친 게임 이름이 섞여 있을 수 있기 때문입니다.

## 한계

- 추출은 **보조 수단**입니다. 확정 목록이 아니라 후보 + 근거 링크를 내놓으니 눈으로 확인하세요
- 제목에 게임 이름이 아예 없는 클립(`1단계 미션 성공` 등)은 원리상 잡을 수 없습니다.
  전 회차 게임을 빠짐없이 원한다면 [나무위키 방영 목록](https://namu.wiki/w/%ED%8B%88%EB%A7%8C%EB%82%98%EB%A9%B4,/%EB%B0%A9%EC%98%81%20%EB%AA%A9%EB%A1%9D)을 함께 보세요
- 사물/동작 사전이 고정 목록이라 새 유형의 게임은 놓칠 수 있습니다.
  `GAME_NOUNS`, `ACTION_SUFFIX`에 낱말을 추가한 뒤 `--from`으로 재추출하면 됩니다
